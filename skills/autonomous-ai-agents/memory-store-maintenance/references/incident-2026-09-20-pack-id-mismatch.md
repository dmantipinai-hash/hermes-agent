# Инцидент 20.09: supersede по id из retrieval-пака заменил ЧУЖУЮ запись

Кейс: обновлялось решение по Bybit. В retrieval-паке виден был id
`f7933bdc` с усечённым превью решения 19.09. Supersede(old_id=f7933bdc,
content=<новое Bybit-решение>) УСПЕШНО исполнился — но id принадлежал
другой активной записи (решение 10.09 об архиве скиллов). Результат:
живое решение о скиллах молча деприкейтнуто, поверх него легла Bybit-
запись с чужим провенансом.

## Корневая причина

Decision table самого скилла говорит: «id from pack line — safe,
works first try». Это верно про МЕХАНИКУ адресации (cross-store id
резолвится — фикс 182f633759 работает), но НЕВЕРНО про ИДЕНТИФИКАЦИЮ:
id в паке ≠ гарантия, что запись с этим id — та, чьё превью рядом.
Усечённые превью двух записей могут выглядеть похожими, а фиксированный
id из кэша/пака может указывать на соседнюю запись.

## Правило (должно попасть в decision table SKILL.md)

**Перед supersede/deprecate по old_id — обязательная сверка id→content:**
`memory(action=read, query=<тема>)` и убедиться, что read вернул ЭТОТ id
рядом с ТЕКСТОМ заменяемой записи. Совпадение первых слов превью —
не критерий (усечённые превью похожи). Только полная пара id+content
из живого read.

Исключение: id получен из ответа САМОГО store в этой же сессии
(напр. `new_id` из предыдущего add/supersede) — там пара гарантирована.

## Восстановление (отработало, 2 операции)

1. Найти настоящий id: read по теме → выбрать запись с правильным
   контентом и типом decision (в кейсе — `273ac2fc`).
2. `supersede(old_id=<правильный id>, content=<новая запись>, reason=...)`
   — целевое обновление.
3. `supersede(old_id=<id ошибочной записи-гибрида>, content=<ОРИГИНАЛЬНЫЙ
   текст замолчалив记录енной записи>, reason="восстановление после
   промаха supersede")` — гибрид деприкейтнут, оригинал снова active
   с чистым провенансом восстановления.

Симптом для детекта в будущем: после supersede в ответе поле
`deprecated_content` НЕ похоже на то, что заменял. Всегда читать его
в ответе — это бесплатная проверка, поймала бы промах мгновенно.
